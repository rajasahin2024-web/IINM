# IINM SEO / AEO — In-depth Implementation Plan

Add a top-level "SEO / AEO" admin menu with sub-pages, plus whole-website SEO + AEO optimization (sitemap, robots, JSON-LD, llms.txt, course SSR wrapper, GSC integration) — without touching any existing business logic.

---

## Architecture Snapshot (existing, NOT changing)

| Layer | Stack | Pattern |
|-------|-------|---------|
| Frontend | Next.js App Router | Server Components + `generateMetadata` + `serverFetch` (ISR) |
| Backend | FastAPI + SQLAlchemy | `routers/*.py`, `models.py`, `require_device` auth |
| Admin | Top-bar dropdown menu driven by `menuData.ts` | `AdminProvider` → `AdminLayout` → page; forms use `apiFetch` + `useToast` |
| Auth | Device-token based | `require_device` dependency on writes |
| SEO fields already in DB | `Course.seo_*`, `BlogPost.seo_*`, `SiteSettings.meta_description` | Exposed in CourseManager + Blog editor |

**Rule:** No existing model column gets renamed/removed. No router signature changes. No business logic touched. Only *additive* changes (new columns, new endpoints, new pages, new menu items, new schema injections).

### A7. `llms.txt` & `llms-full.txt` generation logic
- `llms.txt`: if `SiteSettings.llms_txt` set → return as-is. Else auto-generate from site name + courses list + blog list + about URL.
- `llms-full.txt`: always auto-generated — iterate all PUBLISHED courses (title, slug, description, what_you_will_learn, instructors, FAQs) + published blog posts (title, slug, excerpt, content stripped of HTML, cap 2000 chars) + global FAQs. Markdown formatted.

### A8. SEO score computation (`/api/seo/score`)
Pure function, no AI needed. Checklist:
- title present & 30–60 chars
- description present & 120–160 chars
- canonical set
- OG image set
- JSON-LD schema present (for course/blog)
- ≥1 H1
- internal links ≥3
- image alt texts present
- FAQ block present (AEO)
- question-format heading present (AEO)
Returns `{score: 0-100, checks: [{name, passed, message}], aeo_score: 0-100}`.

### A9. GSC OAuth reuse
Existing `contact.py` has Google OAuth settings (`google_client_id`, `google_client_secret`, `google_redirect_uri`). Reuse same credentials, add scope: `https://www.googleapis.com/auth/webmasters.readonly`. Callback route: `/api/seo/gsc/oauth/callback`. Token stored in `SiteSettings.gsc_refresh_token`.

## Part B — Frontend Public-Site SEO/AEO (whole website)

### B1. `app/sitemap.ts` (Next.js native, ISR)
- `default` sitemap: static pages (/, /courses, /blog, /about-us, /contact-us, /about-iinm).
- `generateSitemaps()` returns `['courses', 'blogs', 'static']` → 3 sitemap files.
- Each fetches via `serverFetch` with `revalidate: 3600` (1h).
- `lastModified` from DB `updated_at`.
- `changeFrequency` + `priority` per type (courses 0.8, blogs 0.7, static 0.5/1.0 for home).
- Excludes: draft/archived courses, draft blogs, `/admin`, `/login`, `/device-*`, `/maintenance`.

- Disallow: `/admin`, `/api`, `/login`, `/device-admin`, `/device-request`, `/maintenance`.

### B7. Course detail page — server wrapper (SAFE approach, business logic intact)
Current `app/courses/[slug]/page.tsx` is `"use client"` (227KB, slot booking, video player, R2 picker, etc.).

**Plan:**
1. Rename current file → `app/courses/[slug]/CourseDetailClient.tsx` (content unchanged, just the file move + `export default function CourseDetailClient(...)`).
2. New `app/courses/[slug]/page.tsx` (server component):
   ```tsx
   import type { Metadata } from "next";
   import CourseDetailClient from "./CourseDetailClient";
   import { serverFetch, isDbDown } from "@/lib/serverFetch";
   import JsonLd from "@/components/JsonLd";

   async function fetchCourse(slug: string) {
     return serverFetch(`/courses/public/courses/${slug}`, 300);
   }

   export async function generateMetadata({ params }): Promise<Metadata> {
     const { slug } = await params;
     const c = await fetchCourse(slug);
     if (isDbDown(c) || !c) return { title: "Course Not Found" };
     const base = process.env.NEXT_PUBLIC_SITE_URL || "https://iinmedu.com";
     return {
       title: c.seo_title || c.title,
       description: c.seo_description || c.description,
       keywords: c.seo_keywords,
       alternates: { canonical: `${base}/courses/${slug}` },
       openGraph: { title: c.seo_title || c.title, description: c.seo_description, images: c.thumbnail_url ? [{ url: c.thumbnail_url }] : undefined, type: "website" },
       twitter: { card: "summary_large_image" },
     };
   }

   export default async function Page({ params }) {
     const { slug } = await params;
     const course = await fetchCourse(slug);
     const faqs = await serverFetch(`/seo/courses/${course.id}/faqs`, 300);
     const courseSchema = { "@context":"https://schema.org","@type":"Course", name: course.title, description: course.seo_description || course.description, provider: {"@type":"Organization", name: site_name}, hasCourseInstance: {...}, offers: {...} };
     const faqSchema = faqs?.length ? { "@context":"https://schema.org","@type":"FAQPage", mainEntity: faqs.map(...) } : null;
     const breadcrumb = { "@type":"BreadcrumbList", ... };
     return (
       <>
         <JsonLd data={courseSchema} />
         {faqSchema && <JsonLd data={faqSchema} />}
         <JsonLd data={breadcrumb} />
         <CourseDetailClient slug={slug} initialData={course} initialFaqs={faqs} />
       </>
     );
   }
   ```
3. `CourseDetailClient` keeps its existing internal `apiFetch` calls for slot booking, video player, etc. — **only the initial load is server-fetched**, removing the loading flash + making HTML crawlable. Existing client logic 100% preserved. Need to adjust `CourseDetailClient` to accept `initialData`/`initialFaqs` props and skip its initial fetch when present.

## Risks & mitigations

| Risk | Mitigation |
|------|-----------|
| Course SSR wrapper breaks slot booking | `CourseDetailClient` keeps all client logic; only initial data passed as prop. Test slot booking end-to-end after. |
| `robots.ts` replaces static file — caching | Next.js handles; deploy + verify `https://iinmedu.com/robots.txt` |
| GSC OAuth complexity | Reuse existing Google API credentials; if scope mismatch, user re-auths. Token stored in DB. |
| Migration on production | All columns nullable, all new tables empty → zero downtime. |
| `llms-full.txt` size grows large | ISR 6h + stream response + gzip. Cap blog content to first 2000 chars per post in dump. |
| `CourseDetailClient` prop shape mismatch | Carefully match `initialData` to what existing `useEffect` fetch was setting; keep `apiFetch` fallback for refresh. |
